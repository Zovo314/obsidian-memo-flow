# Security policy

## Supported versions

Security fixes are provided for the latest published version of Memo Flow.

## Reporting a vulnerability

Please do not publish sensitive vulnerability details in a public issue. Use GitHub's **Report a vulnerability** option in the repository Security tab to open a private security advisory.

Include the affected version, impact, reproduction steps, and any suggested mitigation. Remove personal note content and Vault paths from reports whenever possible.

Memo Flow is designed to operate locally without network access. A regression that transmits note content, accesses files outside the active Vault, or bypasses Obsidian's trash behavior should be treated as a security issue.
