# Changelog

All notable changes to Memo Flow are documented here. The project follows [Semantic Versioning](https://semver.org/).

## [0.1.0] - 2026-09-01

### Added

- Markdown-native memo capture and chronological waterfall.
- Full-text search and tag filtering.
- Edit, pin, archive, link, open, and trash actions.
- Image paste and drag-and-drop with content-addressed storage.
- Desktop and mobile layouts.
- Optimistic edit conflict protection.
- Dependency-free flomo HTML export importer.
- Idempotent import manifests, attachment validation, and conflict reports.
- English and Simplified Chinese documentation.
